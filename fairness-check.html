How the check works

  • Wait is the day a request was closed minus the day it was opened, in calendar days.
  • Areas are compared within one request type at a time. An area with many sidewalk repairs would look slow next to one with mostly missed-trash calls, even if both are served equally well.
  • Typical is the median: the middle request when every wait is lined up, so one request left open for months barely moves it.
  • A gap is a question, not a verdict. Weather, the kind of street, a contractor’s schedule or how fully a request was described can all slow one area down.
  • Real numbers would come from the MC311 Service Requests dataset on dataMontgomery. This prototype uses made-up requests in a similar shape.
